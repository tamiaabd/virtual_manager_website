Import Sales, Purchases and Inventory from Excel

Bring in records you already keep in Excel. Choose the workbook, match its columns to the app’s fields and review the result before saving.

  • .xlsx workbooks
  • Preview before saving
  • Original file unchanged

Prepare one clean sheet first

Save a copy of your workbook as an .xlsx file. Use one row for headings, with descriptive names such as Customer, Item, Quantity and Rate. Use consistent names and units for the same product. Keep notes and grand totals outside the rows you intend to import.

Map columns and preview the import

  1. Open the importer, choose the record type and select the workbook, worksheet and heading row.
  2. Check the suggested column matches. A Sale Price column might map to Rate; an invoice total should not map to a per-unit rate.
  3. Review highlighted rows and check the date, quantity, rate and party on a few transactions you know. Make corrections before confirming.
  4. After saving, open the affected sales or purchases and spot-check totals. For inventory purchases, compare quantities with the stock ledger.

Check customer and item names before you save

For example, if one sheet calls a customer “Ali Traders” and another says “Ali Trading,” decide whether those names refer to the same account. Compare the contact details and sample rows rather than joining them on a similar spelling alone. The same check helps prevent goods of different sizes from becoming one stock item.

Preview: more control over sales import errors

In the upcoming build, stocked sales start as Normal. You can correct or skip problem rows, or explicitly choose Independent for non-stock items or Service for an amount-based service. Missing quantities or rates for Normal and Independent sales must be fixed rather than inferred. Services use a mapped Line Amount, and an optional Service Date defaults to the sale date.
